## 🚀 How to Run

### 1. Clone the Repository

```bash
git clone https://github.com/ravig132/DSA_Java.git
```

### 2. Open the Project

Open the project in **IntelliJ IDEA** or any Java-compatible IDE.

### 3. Select a Java Program

Choose any `.java` file from the repository.

For example:

```text
factorialNum.java
fibonacciSer.java
primeNum.java
palindromeNum.java
HCF.java
LCM.java
```

### 4. Compile and Run

Using the terminal:

```bash
javac FileName.java
java FileName
```

Or run the file directly from your IDE.

## 📊 Complexity Analysis

A major focus of this repository is understanding the efficiency of algorithms.

Common complexities include:

```text
O(1)       Constant
O(log n)   Logarithmic
O(n)       Linear
O(n log n) Linearithmic
O(n²)      Quadratic
O(2ⁿ)      Exponential
```

Understanding **time complexity and space complexity** helps in selecting efficient solutions for programming problems.
